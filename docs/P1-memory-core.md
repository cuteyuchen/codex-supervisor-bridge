# P1 Memory Core

## Goal

Create the persistent memory foundation for Codex Supervisor Bridge.

## Scope

- Task state model
- Independent intent / plan / revision concepts
- Append-only event model
- Decision registry
- Constraint registry
- Context Pack generation

## Non-goals

- Kandev integration
- Codex runtime control
- Remote MCP
- Automated loops

## Current principle

ChatGPT conversation is only a temporary interface. The project state must be recoverable from external memory.
